# Security Policy

Report vulnerabilities privately to **sebastian.rousseau@gmail.com**. Machine-readable disclosure metadata lives at [`/.well-known/security.txt`](.well-known/security.txt) per [RFC 9116](https://www.rfc-editor.org/rfc/rfc9116).

Please do **not** open a public GitHub issue for a suspected security vulnerability — email first to coordinate disclosure.
