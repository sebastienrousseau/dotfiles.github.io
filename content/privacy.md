dotfiles.io is a static website. It sets no cookies, runs no analytics, and loads nothing from a third-party origin: every stylesheet, script and image is served from this domain, and the page's Content Security Policy enforces that.

The site is hosted on GitHub Pages. GitHub may log requests, such as IP addresses, as its [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) describes; this site does not receive or store those logs.

The .dotfiles software itself ships with telemetry disabled. `dot telemetry` shows the current state.
